Multi-Agent + Harness 漏洞挖掘架构

目标不是堆一个更强模型，而是用专职 agent、共享黑板、动态验证和反馈闭环，把 likely 候选推进到 confirmed 漏洞。

打样主指标：confirmed rate

业务方输入资源

  • 复现任务包3-5 个已修复漏洞：vul/fix 源码、patch、描述
  • 可执行环境Docker/compose、构建脚本、依赖缓存、runner 权限
  • 入口与协议fuzz target、CLI、HTTP/RPC、文件格式、seed
  • 动态证据crash log、stack、trace、coverage、请求响应
  • 评测标签root cause、severity、人工审核结论、失败原因

投资诉求

样本资源 业务方提供可复现任务包和安全 owner，保证能判断误报/漏报。
运行资源 amd64 机器、Docker 权限、registry mirror、日志/产物存储。
实验预算 LLM API batch 预算，支持多策略、多轮 attempts、重复实验。
